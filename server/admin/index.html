WebNavi 설정

처음입니다. 이 페이지의 비밀번호를 정하세요. 8자 이상.

차 화면과 같은 아이디·비밀번호로 들어옵니다. 관리자는 모든 설정을, 사용자는 자기 계정의 Tesla · TIDAL 연결과 비밀번호를 바꿀 수 있습니다. 차 화면(/)에 로그인한 브라우저는 바로 들어옵니다. 관리 페이지 비밀번호는 아이디 admin 으로 씁니다.

지금 운행 중

차 화면이 30초마다 알려 줍니다 — 속도, 안내 중인지와 도착까지 남은 시간만. 위치와 목적지는 보내지 않습니다.

설정

키는 암호화되어 서버에만 저장되고, 여기서는 마지막 네 자만 보입니다. 비워 두면 그대로, 지우려면 - 하나만 넣으세요.

경로

주변 (주유 가격 · 충전소)

둘 다 무료 키입니다. 없으면 주유소·충전소도 카카오로 찾되 가격과 빈 충전기 수는 빠집니다.

도로 · 교통

공공데이터포털과 따로 가입해 받는 키입니다.

음성

음악 계정

검증된 기기용(스마트 TV/스트리머) Client ID가 기본 내장되어 있어 전곡(HiFi) 무제한 재생이 가능합니다. 별도 설정 없이 바로 [TIDAL 연결] 버튼을 누르시면 화면에 5자리 인증 코드가 표시됩니다. 스마트폰이나 PC로 link.tidal.com에 접속하여 코드를 입력하면 즉시 연결됩니다. (필요 시 다른 기기 키로 변경도 가능합니다)

TIDAL 계정은 이 사이트의 계정마다 따로 연결합니다. 연결한 계정만 차 화면에 음악 버튼이 나오고, 그 계정의 재생목록·좋아요만 봅니다. 연결과 해제는 로그인한 내 계정에만 됩니다 — 관리자도 다른 계정의 연결은 바꾸지 못합니다.

TIDAL 연결을 누르면 5자리 코드가 나옵니다. 폰이나 PC에서 link.tidal.com 에 들어가 그 코드를 넣으면 연결됩니다.

스마트폰 또는 브라우저에서 아래 링크를 열어 코드를 승인하세요:
link.tidal.com

차량 (Tesla) — 터널 보정

GPS가 끊기는 터널에서 차가 직접 알려 주는 속도·주행거리로 위치를 잇습니다. 차 화면이 열려 있을 때만 받습니다.

PC의 크롬·엣지에서: ① F12로 개발자 도구를 열고 Console 탭을 띄워 둔 채 Tesla 로그인 열기 → 새 탭에서도 F12 → Console. ② 로그인을 마치면 화면은 그대로지만 Console에 Failed to launch 'tesla://auth/callback?code=…' 가 뜹니다. ③ 그 줄을 통째로 복사해 아래에 붙여 넣고 완료. (Tesla Auth 앱 0.13 이상에서 받은 refresh token을 붙여 넣어도 됩니다.)

Tesla 계정은 이 사이트의 계정마다 따로 연결합니다. 연결한 계정만 그 차의 속도·위치를 받고, 다른 계정은 받지 않습니다. 연결과 해제는 로그인한 내 계정에만 됩니다.

이 사이트는 관리자가 Fleet Telemetry 방식으로 차를 연결해 두었습니다. 차는 관리자가 계정에 붙여 줍니다 — 아래 목록에 내 차가 없으면 관리자에게 말하세요.

developer.tesla.com 앱의 Client ID/Secret과, 차가 접속할 텔레메트리 서버 주소(host:port, Cloudflare 프록시를 거치지 않는 포트)를 저장한 뒤 순서대로 누르세요. 리다이렉트 URI:

사용자

    

      
관리자는 이 페이지의 모든 설정을, 사용자는 자기 계정의 Tesla · TIDAL 연결과 비밀번호만 바꿉니다. 둘 다 자기 아이디·비밀번호로 이 페이지에 들어옵니다. 관리 페이지 비밀번호(아이디 admin)는 따로 늘 관리자입니다.

      
차 화면과 폰은 여기서 만든 아이디로 로그인해야 쓸 수 있습니다. 집 · 회사 · 즐겨찾기, 최근 목적지, 안내 설정은 사용자마다 서버에 저장되어 어느 기기에서나 같습니다. 비밀번호를 바꾸면 그 사용자의 다른 기기는 다시 로그인해야 합니다.
