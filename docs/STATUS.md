## 계획서에 없던 것 (추가로 한 것)

- **도커**: 이미지 328 MB, Caddy로 TLS. 컨테이너에서 동작과 볼륨 유지 확인. Caddy는 실제 도메인이 있어야 해서 아직 안 띄워 봄
- **`/admin` 설정 페이지**: 키를 AES-256-GCM으로 암호화해 저장, 비밀번호는 scrypt, 세션 쿠키는 HMAC 서명, 5회 틀리면 잠김. 저장하면 재시작 없이 바로 적용. "연결 확인" 버튼으로 각 서비스를 실제로 한 번 호출해 봄
- **경로 화면 3단계** (한국 내비·구글 내비 구조 참고): 검색(최근 목적지 포함) → 경로 카드(시간, 도착 시각, 거리, 가장 빠름/최단 거리 태그, 혼잡도 막대. 지도에 경로 전부 표시) → 안내 중(회전 화살표 배너, "다음" 안내, 도착 시각, 주행 중 경로 다시 비교, 종료)
- **음악 독**: 오른쪽 아래 미니바. 펼치면 오른쪽 열 전체를 쓰는 플레이어가 되고, 재생목록에서 고르면 다시 접힘
- **모의 주행**: 경로를 따라 1 Hz 가짜 GPS. 속도 슬라이더, 터널, 이탈 버튼
- **`?demo`**: 강남역 → 선릉 OSM 실제 도로로 자동 모의 주행. `&screen=preview`를 붙이면 경로 카드 화면

## 자체 경로 (2026-09-30 시작)

정밀도로지도만으로는 길찾기가 안 된다(고속도로·국도·도심만 있고 이면도로가 없어 출발·도착을 못 잇는다;
받은 구간을 그래프로 보면 조각 455개). 그래서 뼈대는 **전국표준노드링크**(its.go.kr, 2026-09-14판:
링크 156만·노드 118만·회전제한 4.4만), 엔진은 OSRM(MLD), 정밀도로지도는 차로 보정용으로 남긴다.

| compose `osrm` 서비스, nav 의 `korea` 제공자 ("자체" 카드) | 완료 |
| 회전제한 | 완료. 교차로가 내부 링크 고리라 경유 링크(via way) 관계로 변환(1.4만). 고리를 한 바퀴 도는 경로(46만)와 011 유턴 허용에 없는 고리 유턴(19만)은 금지. OSRM 5.26 은 여러 경유 관계에서 customize 가 죽어 **6.0** 사용. 단순 노드의 유턴은 아직 OSRM 기본 벌점(20초)뿐 |
| ITS 실시간 소통정보 → OSRM 속도 | 코드 완료(`server/src/road/traffic.ts`, `tools/nodelink/serve.sh`). 쓰는 동안만 경로 주변 상자를 5분마다. 속도 파일 → customize → datastore 교체까지 20초, 경로 시간·혼잡색 반영 확인(합성 속도로). **ITS 키가 한도 상향 신청 중이라 승인 전까지 4005 거부** — 승인되면 실제 데이터로 확인할 것 |
| 정밀도로지도로 차로 단위 보정 | 미착수 |

ITS 키: 월 30만 건 상향 **승인(2026-10-01)**. 승인 직후 실제 데이터로 확인: 경로 요청 한 번에 상자 1개 → 링크 6.6만 개 속도 → OSRM 반영 → 자체 경로에 혼잡 구간 표시. 호출 절약: 경로 조회만 하면 한 주기(4분)만 받고, 주행 중(돌발상황 폴링이 올 때)에만 10분씩 연장.

## 2026-10-01 화면·안내 손질 (실차 지적 반영)

- 음성의 숫자는 전부 한글 수사("육백미터 앞에", "제한 속도 오십"); "잠시 후 직진"은 안내문이 방면·고가·지하차도 같은 선택을 말할 때만
- 단속 카메라 카드는 지도 위가 아니라 왼쪽 패널의 도착 시각 아래; 구간 단속은 경로 위에 노란 띠(보호구역과 같은 방식); 카메라 아이콘은 카메라 몸통 + 제한속도 표지
- 목적지 창은 지도 위쪽 가운데 버튼에서 아래로 (테슬라 키보드가 아래에서 올라와 입력창을 가렸음). 왼쪽 아래는 비어 있음 — 나중에 다른 정보 자리
- ✕ ▶ ▴ ▾ ✓ 는 테슬라 브라우저에 글리프가 없어 네모로 나와 SVG(`web/src/icons.ts`)로
- 도착하면 안내 종료 옵션(기본 켬, 10초 뒤), 안내 설정에 들어보기 버튼, 야경 건물은 기본 끔·옅게·티맵/네이버 바탕에서만
- 모의 주행이 끝나면 차의 실제 위치로 바로 돌아옴
- **코너 곡선**: 경로의 회전마다 정밀도로지도의 회전 차선 링크를 따라 다시 이어 붙임 (`POST /api/hdmap/thread`, `web/src/thread.ts`). 정밀지도가 있는 곳에서만; 양재→강남 시험에서 회전 4곳 중 정밀지도가 있는 1곳이 바뀜
- **화살표와 길 모양**: 안내마다 경로의 실제 굽음을 재서(±60 m, 그리고 앞 200 m 의 누적 회전) 고리 램프(200° 이상 도는 곳, 성수대교→강변북로)는 루프 화살표로, 안내문이 말한 좌우가 실제 굽음과 25° 이상 반대면 굽음을 따른다(`maneuver.ts shapedOf`)
- **차로 쪽 경로 선**: 정밀지도가 있는 곳에서는 경로 선 전체가 진행 방향 차선들의 가운데로 옮겨진다(`POST /api/hdmap/snap`, 꼭짓점마다; 정밀지도가 끝나는 곳에서는 60 m 에 걸쳐 되돌아옴). 코너 곡선 처리 뒤에 적용
- **경로 선 비틀림 (2026-10-01, 잠실3사거리·올림픽로 Z자)**: 원인 셋 — ① 코너 곡선을 끼울 때 경로 선에서 차선 궤적(넓은 길에서 10 m 옆)으로 직각으로 건너뛰던 것 → 접합점을 궤적 옆거리의 4배(최소 40 m) 앞뒤로 물려 비스듬히 잇고, 궤적이 45° 넘게 비껴 만나거나 대체 구간의 1.6배보다 길면 거부 ② 카카오가 안내 지점을 두 번 넣는데 두 복사본이 진입·진출 방향으로 따로 스냅되어 15 m 옆 교차로 차로로 튀던 것 → 같은 점은 같은 방향(이분선), 서버 궤적의 중복 첫 점 제거 ③ 꼭짓점마다 따로 스냅해 옆으로 뛰는 양을 안 보던 것 → 이웃과 어긋나는 스냅(이웃끼리는 맞는데 혼자 다른 것, 둘이 다르면 선에서 더 먼 쪽)은 버림, 기울기 한도 1 m/6.7 m, 스냅은 좌우 성분만(곡선 차로의 최근접점이 앞뒤로 밀리는 것 제거), 스냅이 만든 50° 이상 꺾임은 되돌림, 끼운 궤적 구간(`route.threaded`)은 스냅하지 않음. 잠실역→잠실3사거리→잠실로 실제 카카오 경로에서 20° 넘는 꺾임 20곳(175° 머리핀 포함) → 1곳(23°). 서버 `SNAP_M 20`·`SNAP_DEG 30` 은 그대로(실측상 문턱이 아니라 방향·접합이 원인)

## 2026-10-01 정밀도로지도의 신호등·방지턱

`build.py --layers lights,bumps` 로 C1/SF3 신호등(차량용만: 2019 Type 1~9, 2024 LightType 1xx)과 C4/SF5 방지턱(폴리곤의 중심)을 뽑아 `safety/hd-points.ts` 가 안전 색인에 넣는다. 같은 종류의 공공데이터 점이 20 m 안에 있으면 정밀지도 점만 남긴다(두 번 그리거나 말하지 않게). 파일이 바뀌면 한 시간 안에 다시 읽는다. **안전표지(B1/SF2)는 뺐다**: 제한속도 표지라는 종류(224)만 있고 속도 값이 없어 과속 경고에 쓸 수 없다.

자체 경로 카드는 실시간 속도가 하나도 안 붙은 경로면 내지 않는다(그 지역 속도가 들어오기 전 첫 조회의 경로는 제한속도로 달려 더 빠르게 보였음).

## 2026-10-01 자체 경로 ETA 보정

OSRM 은 실시간 속도가 없는 링크를 제한속도로 달려 시내에서 너무 빠르게 나왔다(강남→왕산로 23분, 3사 36~47분). `osrm.ts calibrateDuration`: 단계마다 실시간 속도가 **없는 비율**만큼 시내 ×1.2 + 400 m 당 12초(신호), 고속도로 ×1.05, 회전은 항상(좌·유턴 15초, 우 8초, 회전교차로 10초). 실시간 구간은 ITS 링크 속도에 신호 대기까지 들어 있어 그대로 둔다. 2026-10-01 14시 비교: 강남→왕산로 33.7분(3사 35.8/47/37.7), 강남→판교 21.3(27.1/28.6/22.4), 강남→선릉은 실시간 구간이 대부분이라 보정 전에도 9.0(3사 6/6.6/8.3) — 이쪽은 ITS 링크 속도 자체가 낮게 와서 생기는 차이.

## 2026-10-01 실차 주행 검증 및 고도화 (화면 위치·터널·오디오·음성·차선 편향)

실차 주행 테스트 피드백 반영:
- **차량 위치 중앙 정렬**: 상단 HUD 카드 너비가 하단 차량의 화면 좌측 여백으로 잡혀 우측으로 약 130px 치우치던 현상 수정 (`carSpot`). 이제 화면 정중앙 하단에 위치
- **음악 전환 시 화면 튐 & 오디오 끊김 제거**: 메인 스레드 지연 시 한 프레임 보간 계수가 95% 이상으로 치솟아 순간이동하던 현상 방지(`followCar` 단일 프레임 보간 계수 최대 0.55 클램핑). 앨범아트 Canvas 색상 분석(`wearTint`)을 400ms 지연 실행하여 오디오 디코딩 버퍼 확보
- **지하터널 추측 항법 헤딩 반전(180° 뒤쪽) 수정**: 터널 안에서 `shownAt`은 전진하지만 내부 누적 거리 `shownAlong`이 갱신되지 않아 카메라 선독 점이 차량 뒤쪽을 향하던 버그 수정. `this.shownAlong = reckoned.alongM` 갱신 및 도로 진행 방향 헤딩(`ahead.bearing`) 직접 추종
- **좌·우회전 음성 안내 ("잠시 후 좌/우회전") 누락 방지 & 사전 로딩**: 회전 안내 유효 시간(`TURN_WITHIN_S`)을 10초에서 25초로 확장하여 다른 경고음이나 서행 중 조기 만료 폐기 방지. 원거리 안내(300m/500m) 발화 즉시 다음 "잠시 후" 음성을 백그라운드 프리페치하여 0초 즉시 재생
- **정밀지도 최적 차선 진입 편향 (Lane Biasing)**: 회전 교차로 250m 전부터 진행 방향 편향(`bias`)을 계산하여, 좌회전/유턴은 좌측 1~2차로로, 우회전은 우측 차로로 경로선 자체가 서서히 최적 차선에 진입하도록 스냅 알고리즘 개선 (`lanes.snap`, `thread.ts computeBiases`)
