## 계획서에 없던 것 (추가로 한 것)

- **도커**: 이미지 328 MB, Caddy로 TLS. 컨테이너에서 동작과 볼륨 유지 확인. Caddy는 실제 도메인이 있어야 해서 아직 안 띄워 봄
- **`/admin` 설정 페이지**: 키를 AES-256-GCM으로 암호화해 저장, 비밀번호는 scrypt, 세션 쿠키는 HMAC 서명, 5회 틀리면 잠김. 저장하면 재시작 없이 바로 적용. "연결 확인" 버튼으로 각 서비스를 실제로 한 번 호출해 봄
- **경로 화면 3단계** (한국 내비·구글 내비 구조 참고): 검색(최근 목적지 포함) → 경로 카드(시간, 도착 시각, 거리, 가장 빠름/최단 거리 태그, 혼잡도 막대. 지도에 경로 전부 표시) → 안내 중(회전 화살표 배너, "다음" 안내, 도착 시각, 주행 중 경로 다시 비교, 종료)
- **음악 독**: 오른쪽 아래 미니바. 펼치면 오른쪽 열 전체를 쓰는 플레이어가 되고, 재생목록에서 고르면 다시 접힘
- **모의 주행**: 경로를 따라 1 Hz 가짜 GPS. 속도 슬라이더, 터널, 이탈 버튼
- **`?demo`**: 강남역 → 선릉 OSM 실제 도로로 자동 모의 주행. `&screen=preview`를 붙이면 경로 카드 화면
- CSV 로그 재생, WebGL이 없을 때 안내 문구, 지도 스타일을 못 받으면 빈 바닥으로 대체
- **지도 조작** (2026-09-29): 3D/2D 진행 방향/북쪽 고정 모드, 끌기·회전·기울이기는 자유 보기
  (핀치 확대는 따라가기 유지), 안내 중 12초 뒤 자동 복귀, 현위치·확대/축소 버튼, 차를 화살표로
- **주변 카테고리** (2026-09-29): 주유소(오피넷 가격)·충전소(환경공단 빈 충전기, 환경부 요금)·주차장·
  음식점·카페·편의점·병원·약국·은행·휴게소. 여러 종류 동시 표시, 거리순/가격순, 유종 선택,
  경로 위만, 상세 → 목적지로. 주행 중 목적지를 바꿔도 카드를 닫으면 원래 목적지 유지

## 자체 경로 (2026-09-30 시작)

정밀도로지도만으로는 길찾기가 안 된다(고속도로·국도·도심만 있고 이면도로가 없어 출발·도착을 못 잇는다;
받은 구간을 그래프로 보면 조각 455개). 그래서 뼈대는 **전국표준노드링크**(its.go.kr, 2026-09-14판:
링크 156만·노드 118만·회전제한 4.4만), 엔진은 OSRM(MLD), 정밀도로지도는 차로 보정용으로 남긴다.

| 단계 | 상태 |
|---|---|
| 표준노드링크 → OSM → OSRM 그래프 (`tools/nodelink/build.py`) | 완료. 전국 그래프 생성 약 5분, 강남→부산 경로 44 ms |
| compose `osrm` 서비스, nav 의 `korea` 제공자 ("자체" 카드) | 완료 |
| 회전제한 | 완료. 교차로가 내부 링크 고리라 경유 링크(via way) 관계로 변환(1.4만). 고리를 한 바퀴 도는 경로(46만)와 011 유턴 허용에 없는 고리 유턴(19만)은 금지. OSRM 5.26 은 여러 경유 관계에서 customize 가 죽어 **6.0** 사용. 단순 노드의 유턴은 아직 OSRM 기본 벌점(20초)뿐 |
| ITS 실시간 소통정보 → OSRM 속도 | 코드 완료(`server/src/road/traffic.ts`, `tools/nodelink/serve.sh`). 쓰는 동안만 경로 주변 상자를 5분마다. 속도 파일 → customize → datastore 교체까지 20초, 경로 시간·혼잡색 반영 확인(합성 속도로). **ITS 키가 한도 상향 신청 중이라 승인 전까지 4005 거부** — 승인되면 실제 데이터로 확인할 것 |
| 정밀도로지도로 차로 단위 보정 | 미착수 |

ITS 키: 월 30만 건 상향 **승인(2026-10-01)**. 승인 직후 실제 데이터로 확인: 경로 요청 한 번에 상자 1개 → 링크 6.6만 개 속도 → OSRM 반영 → 자체 경로에 혼잡 구간 표시. 호출 절약: 경로 조회만 하면 한 주기(4분)만 받고, 주행 중(돌발상황 폴링이 올 때)에만 10분씩 연장.
`type=ex` 호출은 401 이라 `type=all` 로만 받는다.

## 2026-10-01 화면·안내 손질 (실차 지적 반영)

- 음성의 숫자는 전부 한글 수사("육백미터 앞에", "제한 속도 오십"); "잠시 후 직진"은 안내문이 방면·고가·지하차도 같은 선택을 말할 때만
- 단속 카메라 카드는 지도 위가 아니라 왼쪽 패널의 도착 시각 아래; 구간 단속은 경로 위에 노란 띠(보호구역과 같은 방식); 카메라 아이콘은 카메라 몸통 + 제한속도 표지
- 목적지 창은 지도 위쪽 가운데 버튼에서 아래로 (테슬라 키보드가 아래에서 올라와 입력창을 가렸음). 왼쪽 아래는 비어 있음 — 나중에 다른 정보 자리
- ✕ ▶ ▴ ▾ ✓ 는 테슬라 브라우저에 글리프가 없어 네모로 나와 SVG(`web/src/icons.ts`)로
- 도착하면 안내 종료 옵션(기본 켬, 10초 뒤), 안내 설정에 들어보기 버튼, 야경 건물은 기본 끔·옅게·티맵/네이버 바탕에서만
- 모의 주행이 끝나면 차의 실제 위치로 바로 돌아옴
- **코너 곡선**: 경로의 회전마다 정밀도로지도의 회전 차선 링크를 따라 다시 이어 붙임 (`POST /api/hdmap/thread`, `web/src/thread.ts`). 정밀지도가 있는 곳에서만; 양재→강남 시험에서 회전 4곳 중 정밀지도가 있는 1곳이 바뀜
- **화살표와 길 모양**: 안내마다 경로의 실제 굽음을 재서(±60 m, 그리고 앞 200 m 의 누적 회전) 고리 램프(200° 이상 도는 곳, 성수대교→강변북로)는 루프 화살표로, 안내문이 말한 좌우가 실제 굽음과 25° 이상 반대면 굽음을 따른다(`maneuver.ts shapedOf`)
- **차로 쪽 경로 선**: 정밀지도가 있는 곳에서는 경로 선 전체가 진행 방향 차선들의 가운데로 옮겨진다(`POST /api/hdmap/snap`, 꼭짓점마다; 정밀지도가 끝나는 곳에서는 60 m 에 걸쳐 되돌아옴). 코너 곡선 처리 뒤에 적용
- 성능: 프레임마다 지도를 세 번 움직이던 것을 한 번으로(중심 계산은 transform 복사본에서), 티맵·네이버 바탕은 프레임당 한 번만 동기화, 차가 서 있고 카메라가 자리 잡으면 이동 생략, 라벨 페이드 끔. 실차 체감은 확인 필요
- 바탕 지도는 티맵만(네이버는 기울여도 평면이라 뺌, 카카오는 SDK 가 회전·기울기 없음, OSM 은 키 없을 때 대체용). 바탕 선택 버튼은 `?debug` 에서만. 북쪽 고정 화면 삭제(3D·2D). 안내 설정 → 지도 해상도 "빠르게"(1배 렌더링) 추가 — 실차에서 체감 확인 필요
- 자체 경로는 **ITS 소통정보가 실제로 한 번 수신된 뒤에만** 후보로 나옴 (승인 대기 중에는 숨김, 승인되면 다음 경로 요청부터 자동)

안내 중 6분마다 티맵·카카오·네이버·자체(소통정보 수신 중일 때) 경로를 다시 받아 3분 이상 빠른 길이 있으면: 새 길을 지도에 옅게 같이 그리고, 패널에 "카카오 경로 · 4분 단축 [바꾸기] [그대로]" 카드와 음성("사분 빠른 길이 있습니다"). 안내 설정 → 더 빠른 길: **20초 뒤 자동**(기본, 그대로를 누르지 않으면 전환) · 물어보기(탭해야 전환) · 끔. 그대로를 누르면 그 길보다 3분 이상 더 빠른 길이 나올 때까지 다시 묻지 않는다.

## 2026-10-01 외부 코드 리뷰 문서 검토

받은 리뷰 문서(성능·화질·로직)를 코드와 대조한 결과:

| 항목 | 판정 | 처리 |

| 9곳의 backdrop-filter 블러 | 맞음 | "지도 해상도: 빠르게" 에서 모든 블러 끔(`body.fast`). 기본은 유지 |
| 티맵 동기화의 queueMicrotask 가 1프레임 늦다 | 틀림 | 마이크로태스크는 같은 프레임의 스크립트 직후, 렌더링 전에 실행됨. 그대로 둠 |

| 보간이 도로 곡선을 가로지름(chord) | 맞음(정도는 과장) | 경로 위에 있을 때는 두 위치의 경로상 거리를 보간해 `place()` 로 그림 |

| 음성 큐: 다운로드 뒤 만료 재확인 | 맞음 | buffer 획득 뒤 `until` 을 다시 확인 |

- 소리가 나면: 음악은 순정 앱으로 듣고 이 페이지는 안내 음성만 내면 됨. 덕킹은 안 됨
- 막히면: 음악도 이 페이지에서 틀어야 함(TIDAL, 지금은 30초까지)

## 남은 일 (권하는 순서)

1. **차 페이지 접근 키**: 지금은 도메인을 아는 사람이면 누구나 `/api/*`를 부를 수 있음. 경로·TTS 비용이 나가고, TIDAL 토큰도 받아 갈 수 있음. `/admin`에서 긴 키를 만들어 차 브라우저에 한 번 넣는 방식으로
2. **실제 키로 검증**: TMAP·카카오·네이버·DashScope 키를 `/admin`에 넣고 "연결 확인" → 실제 경로 카드와 음성 확인
3. **공공데이터 CSV 넣기**: 경찰청 무인교통단속카메라, 행안부 과속방지턱
   - **오피넷 키·공공데이터포털 키**도 `/admin`에 넣고 "연결 확인". 특히 충전소 API의 `zscode`
     (시군구) 조회가 실제로 되는지, 강원(51/42)·전북(52/45) 코드 중 무엇이 맞는지는 실제 키로만 확인됨
4. **TIDAL 전곡 경로 실차 확인**: 다른 탭의 tidal.com 웹 플레이어, 또는 Music Assistant 웹 플레이어
5. **실차**: GPS 필드(heading/speed 제공 여부, 수신 주기), Widevine, 순정 오디오와의 공존, Wake Lock, 메모리
6. NUC 배포: 도메인 + 포트포워딩 또는 Cloudflare Tunnel

**실제 키 확인 (2026-09-29, 도커 :8088)**: 티맵·카카오·네이버 경로 ✅, 오피넷 가격 ✅, 음성 ✅,
충전소 ✅(시군구를 티맵 역지오코딩으로), 티맵 벡터 바탕 지도 ✅. 남은 것: 카카오 앱의 **카카오맵 사용 설정 OFF**
(검색·주변 403), 티맵 경로에 구간별 혼잡도(`traffic`)가 안 옴(요청 방식 3가지 모두 — 요금제 추정).

화면 쪽으로 더 볼 만한 것: 낮 모드(일몰 기준 자동 전환), 차선 안내(TMAP·카카오가 주는 정보),
**경유지 추가**(주변에서 고른 주유소를 목적지 대신 경유지로 — 3사 모두 경유지 파라미터가 있음),
지도 길게 눌러 목적지, 테슬라 슈퍼차저(환경공단 피드에 없을 수 있음)
